# Demo Script

1. Open the UI and log in as `admin@appsec.local`.
2. Show the dashboard metrics and model status.
3. Open Projects and select `FastAPI Lab Demo`.
4. Open the target wizard, confirm `http://localhost:8008`, paste/review scope, and start a safe-active scan.
5. Watch scan events: prepare, map, context, plan, run checks, verify, report.
6. Open endpoint graph and filter by authenticated endpoints.
7. Open confirmed findings and show evidence, verifier decision, business impact, remediation, and suggested test.
8. Export HTML/PDF report.
9. Run CLI `appsec ci --scan-id <id> --fail-on high` to show the CI gate behavior.
